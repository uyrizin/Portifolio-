# Yuri Higa — Portfólio de Cibersegurança

Portfólio profissional de Yuri Higa, estudante de Tecnologia em Cibersegurança na FIAP, com foco em Application Security (AppSec), análise de vulnerabilidades e segurança ofensiva.

Desenvolvido com **Next.js 14**, **TypeScript** e **Tailwind CSS**.

## Foco do portfólio

- Apresentação profissional e formação em Cibersegurança.
- Projetos autorais e laboratórios em desenvolvimento.
- Conhecimentos em AppSec, Linux, redes, Cloud Security e DevSecOps.
- Links para GitHub e LinkedIn.

## Projetos apresentados

| Projeto | Descrição | Situação |
|---|---|---|
| AEGIS | Framework modular para apoiar avaliações e auditorias de segurança em ambientes autorizados. | Em desenvolvimento |
| WiFi Sentinel | Diagnóstico, monitoramento e auditoria de redes Wi-Fi em ambientes autorizados. | Em desenvolvimento |
| ORION | Automação e inteligência com recursos de IA. | Em desenvolvimento |
| Android Mirror | Espelhamento de tela Android, com foco em comunicação em tempo real. | Em desenvolvimento |

A página pública diferencia projetos em desenvolvimento de funcionalidades implementadas. Nenhum segredo, credencial, dado privado ou código proprietário deve ser publicado neste repositório.

## Tecnologias do site

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Vitest e React Testing Library
- Vercel para hospedagem (quando conectado ao projeto)

## Executar localmente

Requisitos: Node.js 18 ou superior.

```bash
npm install
npm run dev
```

Acesse http://localhost:3000.

## Verificações

```bash
npm run lint
npm test
npm run build
```
